## Decisions Made
| Decision | Rationale |
|----------|-----------|
| Vite + React + TypeScript | Stack moderno, rápido, recomendado por brief |
| Tailwind CSS v3 | Utility-first, fácil customización con paleta |
| Motion for React (Framer Motion) | Animaciones fluidas declarativas |
| Lucide React | Iconografía consistente |
| Proyecto desde cero | Directorio vacío confirmado |
